# ADR-002: Реализация выбора карточек для практики (SRS Probabilistic Sampling)

## Статус
Принято

## Контекст
В рамках задачи [CORE]-[003] потребовалось реализовать взвешенный выбор 10 карточек без повторений для практики на основе их текущего веса (Probabilistic Sampling). Стандартная библиотека Python (`random.sample`) не поддерживает взвешенную выборку (`weights=...`). Метод `random.choices` поддерживает `weights`, но осуществляет выборку *с возвращением* (допускает дубликаты). 

## Решение
Реализован алгоритм последовательной выборки без возвращения на базе `random.choices`:
1. Из базы извлекаются карточки пользователя с `weight > 0`.
2. Копируются доступные карточки и их веса в списки (`pool`).
3. В цикле выполняется выбор по одному случайному элементу через `random.choices` с учетом актуального списка весов.
4. Выбранная карточка добавляется в результирующий список, а из `pool` удаляется как сама карточка, так и ее вес (для исключения повторного выпадения).
5. Процесс повторяется до набора требуемого количества карточек (по умолчанию 10) или исчерпания пула.

Такой подход позволяет сохранить строгое статистическое распределение без подключения внешних тяжелых зависимостей вроде `numpy`, что удовлетворяет требованию KISS.

## Последствия
- **Положительные:** Код остается легким (используется только stdlib Python), нет внешних зависимостей. Требования продуктового документа к SRS выполняются строго математически.
- **Отрицательные:** Алгоритм требует мутации списков на каждую операцию. Это может быть проблемой производительности при выборке 10 элементов из пула в несколько тысяч? Сложность O(K * N), где K=10, N - размер словаря, что на практике означает время работы за долю миллисекунды, поэтому проблема пренебрежимо мала для текущего контекста и объемов профиля пользователя.
