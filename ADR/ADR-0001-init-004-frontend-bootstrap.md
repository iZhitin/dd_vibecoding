# ADR-0001: Bootstrap frontend в INIT-004

**Статус:** Принято  
**Дата:** 2026-02-24  
**Связанные задачи:** [INIT-004]

## Контекст

В задаче `[INIT]-[004]` требовалось поднять frontend на React + Vite + Tailwind + Zustand и сразу обеспечить рабочую маршрутизацию-заглушку для ключевых страниц. Параллельно в репозитории ещё нет полноценного UI-дизайна и доменных экранов.

## Решение

1. Использовать стандартный Vite bootstrap для `react-ts` как базу проекта, чтобы избежать кастомной структуры на раннем этапе.
2. Подключить Tailwind через `@tailwindcss/vite` и базовые монохромные стили в `src/index.css`, без избыточной дизайн-системы до появления продуктовых экранов.
3. Сразу ввести минимальный каркас роутинга (`/login`, `/capture`, `/practice`, `/history`, `/review`) с редиректом `/ -> /capture`, чтобы следующие задачи могли развивать страницы независимо.

## Последствия

- Плюсы:
  - минимальный, предсказуемый стартовый фронтенд без технического долга;
  - готовый skeleton маршрутов для последующих задач;
  - единый визуальный baseline (монохром, типографический минимализм) в соответствии с PRD.
- Минусы:
  - страницы пока являются заглушками и требуют дальнейшего наполнения;
  - отсутствует централизованный layout-компонент (будет добавлен в следующих задачах UI-слоя).
