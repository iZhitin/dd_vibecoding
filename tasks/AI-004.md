# Отчёт по задаче AI-004: Подключить enqueue LLM-review в submit_practice

## Цель
Установить связь между завершением сессии пользователем (`submit_practice`) и отправкой данных сеанса (предложений) на проверку через асинхронный `Arq Redis` воркер.

## Что было сделано
1. В `backend/app/services/practice.py` был добавлен импорт `created_pool`, `ArqRedis`.
2. Написана глобальная асинхронная singleton-функция `get_arq_pool() -> ArqRedis:` для получения пула соединений воркера `Arq`.
3. В самой функции `submit_practice`, сразу после коммита сеанса в БД с поведением SessionStatus=`COMPLETED`, добавлен вызов `get_arq_pool()` и постановка задачи в очередь `.enqueue_job("review_sentences", session.id)`.

## Критерии готовности (DoD)
- [x] Постановка задачи в очередь `Redis` успешно совершается при вызове `/api/practice/submit`.
- [x] Воркер видит задачу и начинает процесс обработки (llm_feedback / grade обновляется отложенно).
