# Отчёт по задаче AI-001: Настроить Arq worker и подключение к Redis

## Цель
Настройка базового воркера задач через Arq для обработки асинхронных задач и подключение к локальному или продакшн Redis.

## Что было сделано
1. Был создан конфигурационный файл `backend/app/workers/config.py`.
2. В нем определен класс `WorkerSettings` со списком функций (пока пустая функция `review_sentences`) и настройками `RedisSettings`, которые извлекаются из переменных окружения.
3. Добавлен сервис `worker` в `docker-compose.yml`, который использует `arq app.workers.config.WorkerSettings` как точку входа.

## Критерии готовности (DoD)
- [x] Команда `arq app.workers.config.WorkerSettings` запускается корректно.
- [x] Воркер успешно подключается к Redis.
- [x] Воркер интегрирован в `docker-compose.yml`.
