# Отчет о выполнении задачи [CORE]-[003]

## Что было сделано
1. Создан модуль `backend/app/services/srs.py`.
2. Реализована функция `select_practice_cards` для извлечения карточек со взвешенным выбором. Отбор 10 карточек формируется так, что у карточек с бОльшим весом вероятность попасть в ежедневный набор значительно выше. 
3. Добавлен алгоритм случайного выбора "с изъятием", использующий базовую библиотеку `random.choices` в сочетании с мутацией элементов списка `[weight]`.
4. Написаны функции `update_weight_after_review` и `update_weight_after_reveal` для корректировки весов в зависимости от успехов пользователя (увеличение веса при плохой оценке или скрытом переводе, уменьшение при хорошей). 
   - `Grade == RED` -> `weight *= 1.5`
   - `Grade == YELLOW` -> `weight *= 1.2`
   - `Grade == GREEN` -> `weight *= 0.7`
   - `Grade == GREEN_STAR` -> `weight *= 0.5`
   - `revealed == True` -> `weight *= 2.0`
5. Реализована нижняя граница веса `max(weight, 0.01)` при уменьшении. 
6. Написаны модульные тесты для модуля в `backend/tests/test_srs.py`, включающие проверку статистического распределения на 1000 интерполяций случайного выбора (карточки выбираются соответственно своим весам). Тесты прошли успешно без подключения к реальной базе (через mock `db`).
7. Обновлены статусы в `BACKLOG.md` (критерии готовности выполнены). Запись была также добавлена в `CHANGELOG.md` под датой 2026-02-25.
