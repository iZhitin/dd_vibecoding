# Отчет по задаче [NOTIFY-003] Реализовать Smart Nudge (Reminder)

## Описание
В рамках этой задачи была спроектирована и внедрена система "мягких" напоминаний (Smart Nudge) о необходимости практики для пользователей приложения.

## Что было сделано:
- **Воркер по расписанию**: Создан скрипт `backend/app/workers/scheduler.py` с асинхронной процедурой `smart_nudge_check`.
- **Логика расчёта времени**: Напоминание отправляется, если в часовом поясе пользователя наступило время `avg_practice_time` + 1 час. 
- **Защита от дублей**: Для предотвращения спама в течение одного дня добавлена проверка отправки через `ArqRedis` кеш с TTL = 24 часа. Осуществлена проверка, практиковался ли уже студент в эти сутки (`last_practice_at.date() == user_now.date()`).
- **Интеграция**: Крон-задача `smart_nudge_check` добавлена в `app.workers.config.WorkerSettings` для ежечасного срабатывания (`cron(smart_nudge_check, minute=0)`).
- **Обновление статистики**: Обновлен контроллер отправки практики `submit_practice`. Теперь `avg_practice_time` обновляется по факту прохождения `SessionStatus.COMPLETED`.
- Запуск линтеров (`ruff`) и все автотесты `pytest` выполнены успешно. Архитектура не нарушена.

## Ссылки на ADR
Не требуется (принята упрощённая MVP-схема `new_avg_time = current_practice_time` согласно беклогу).

## Статус
Выполнена и полностью закрыта по DoD, код зафиксирован.
