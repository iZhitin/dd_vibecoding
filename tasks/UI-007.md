# [UI]-[007] Настроить Service Worker и PWA manifest

**Статус:** ✅ Выполнено
**Дата:** 2026-02-26

## Что сделано

### 1. Иконки PWA
- Сгенерирована иконка приложения «DD» в минималистичном монохромном стиле
- Созданы размеры: 512x512, 192x192, 180x180 (apple-touch-icon), 32x32and 16x16 (favicon)
- Файлы размещены в `frontend/public/`

### 2. Конфигурация vite-plugin-pwa (vite.config.ts)
- Добавлены `includeAssets` для статических иконок
- Расширен `manifest`: добавлены `start_url`, `scope`, `purpose: "any maskable"` для иконки 512x512
- Настроен Workbox:
  - `globPatterns` для кэширования статических ассетов (js, css, html, ico, png, svg, woff2)
  - `navigateFallback: "index.html"` для SPA fallback
  - `navigateFallbackDenylist: [/^\/api/]` — API-запросы исключены из кэширования Service Worker

### 3. Обновлён index.html
- Добавлен `<meta name="theme-color">`
- Добавлен `<meta name="description">`
- Добавлен `<link rel="apple-touch-icon">`
- Favicon заменен с несуществующего `vite.svg` на PNG-иконки
- Улучшена SEO-обвязка

### 4. Верификация
- `npm run build` — успешно, PWA генерируется (15 precached entries, 384 KiB)
- `manifest.webmanifest` содержит все необходимые поля
- `sw.js` и `workbox-*.js` сгенерированы
- Все 32 backend-теста проходят
- `npm run lint` — без ошибок
