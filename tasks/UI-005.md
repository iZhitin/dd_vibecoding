# Отчёт о задаче UI-005

**Задача:** Создать страницу History (список слов и статистика)
**Статус:** Выполнена

## Что сделано:

1. **Создан компонент StreakBadge:**
   - Компонент вынесен в `frontend/src/components/StreakBadge.tsx`.
   - Крупно отображает текущий стрик (`streak_current`) 
   - Выводит количество заморозок (`streak_frozen_count`), если они есть.
   - Красивые анимации появления и стильный, крупный и монохромный дизайн.

2. **Backend API обновлен для сортировки:**
   - Эндпоинт `GET /api/cards` в `cards.py` расширен параметром `sort_by`: `date` или `weight`.
   - В слое сервиса `get_user_cards` добавлена логика `order_by` либо `weight.desc()`, либо `created_at.desc()`.
   - Это гарантирует, что сортировка по весу будет работать глобально, а не только на клиенте для уже загруженной страницы.

3. **Frontend API Client обновлен для сортировки:**
   - `frontend/src/api/cards.ts` принимает параметр сортировки и передает его в queryString.

4. **Создана страница HistoryPage:**
   - Использован минималистичный монохромный дизайн Tailwand CSS.
   - Стрик выводится на самом видном месте через StreakBadge.
   - Выводится список карточек (Слово, Перевод, Дата добавления и визуализированный «Вес» карточки в виде прогресс бара). 
   - Поддерживается Infinite pagination или Load More кнопка.
   - Пользователь может выбрать Select sorting: Newest / Heaviest.
   - При смене сортировки список сбрасывается и загружается заново.

5. **Тесты и Линтинг:**
   - Запущен `npm run lint` & `npx prettier`.
   - Проверены бэкенд тесты (`pytest tests/test_cards.py`) и линтинг (`ruff check app/`).
