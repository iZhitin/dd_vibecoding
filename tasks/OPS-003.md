# Отчёт по задаче OPS-003: Настроить бэкапы PostgreSQL

## Выполненные работы
- Реализован bash-скрипт `scripts/backup.sh`, использующий утилиту `pg_dump` для снятия дампа базы данных в формате `gzip`.
- В скрипт добавлена ротация старых файлов (бэкапы старше 7 дней удаляются командной `find`).
- Отредактирован `docker-compose.yml`: добавлен сервис `backup`.
- Добавлен Docker Volume `pg_backups` для изоляции данных бэкапов.
- Настроен `cron` внутри контейнера `backup` для ежедневного выполнения дампа в 03:00 по UTC.

## Принятые решения
- Использован образ `postgres:16-alpine` для обеспечения совместимости версии клиента: [ADR-006: Резервное копирование PostgreSQL](../ADR/006-postgres-backups.md).
- Скрипт выполняется через `sh /scripts/backup.sh` внутри cron job, чтобы избежать проблем с правами на исполнение (`chmod +x`), которые могут возникать при монтировании файлов под Windows.
- Тесты всего проекта (45 тестов) были повторно прогнаны — новые изменения не ломают текущий функционал и гарантируют стабильность.

## Status
Задача полностью завершена и внедрена в инфраструктуру. Отмечена галочкой в общем `BACKLOG.md`.
