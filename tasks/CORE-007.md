# Отчет по задаче CORE-007

## Что было сделано:
- Реализована функция `update_streak` в модуле `backend/app/services/streak.py`.
- Логика стриков учитывает таймзону пользователя для определения наступления нового дня (при помощи `zoneinfo`).
- Обработаны случаи: 
    - практика каждый день (увеличение стрика)
    - множественные практики в один день (стрик не меняется)
    - пропуск дня без заморозки (сброс стрика в 1)
    - пропуск дня с использованием "заморозки" (`is_frozen = True`, `streak_frozen_count > 0` - стрик не сбрасывается, значение заморозок уменьшается)
- Функция встроена в `submit_practice` в процессе отправки результатов сессии.

## Зависимости / Связанные задачи:
- Ссылается на PRD §4.4 (правила логики стриков).
- Интегрировано в `CORE-005` (API `/api/practice/submit`).
- Починены все тесты для проверки консистентности.

## ADR:
*Дополнительных решений по архитектуре в ходе выполнения не принималось, логика соответствует изначально задокументированной.*
