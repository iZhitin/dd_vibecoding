# Отчет о выполнении задачи [SEC-002]

## Описание задачи
Настроить rate limiting для предотвращения брут-форс атак (magic tokens) и abuse API (translate, practice).

## Ключевые изменения
1. В приложение FastAPI добавлен `slowapi` (`Limiter`), инициализированный в `app/core/rate_limit.py`. Установлен глобльный лимит "60/minute".
2. Настроено подключение исключения `RateLimitExceeded` к FastAPI `app` для возврата корректного HTTP статуса `429 Too Many Requests`.
3. На эндпоинт отправки magic-токена `/api/auth/login` прикреплён более строгий лимит `"5/minute"`.
4. На эндпоинт `/api/translate` добавлен лимит запросов `"20/minute"`.
5. В `nginx/nginx.conf` установлен лимит `10m rate=30r/s; burst=50 nodelay`, что предотвращает спам-атаки и L7 DDoS на API.

## Статус
Выполнено.
