# Задача: [CORE]-[004] Реализовать GET /api/practice/daily — генерация сессии

## Описание
Реализован эндпоинт для генерации ежедневной практической сессии на 10 карточек с использованием SRS-алгоритма.
Для каждой карточки подгружается предыдущее предложение пользователя из `PracticeLog` (Context Cue).

## Что было сделано:
1. Создан `backend/app/services/practice.py` с функцией `generate_daily_session`. Использован `select_practice_cards` из сервиса `srs` для генерации 10 карточек.
2. Реализована логика проверки наличия активной сессии. Если таковая имеется, возвращается именно она, чтобы избежать создания паразитных сессий.
3. Добавлен роутер `practice` в `backend/app/api/routes/practice.py` с эндпоинтом `GET /api/practice/daily`.
4. Роутер `practice` подключён в `main.py`.
5. Написан тест в `backend/tests/test_practice.py` для тестирования функционала.
6. Выправлены мелкие проблемы с тайп-хинтами и форматированием через `ruff`.

## Решения (ADR)
Нет новых ADR, следовал существующим (`002-srs-probabilistic-sampling.md`).

## Статус
Выполнена, тесты и линтинг проходят (100% покрытие для нового функционала).
