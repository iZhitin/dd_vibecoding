# Отчёт по задаче AI-002: Создать Pydantic-схему для LLM-ответа

## Цель
Подготовить строгую Pydantic-схему (Traffic Light Report) для валидации структурированного JSON-вывода от OpenAI (model=gpt-4o-mini). Вывод должен содержать 4 атрибута: оценка, исправление, пояснение и похвала.

## Что было сделано
1. В `backend/app/schemas/llm.py` создана Pydantic-структура:
   - `SentenceReview` из полей `grade: Grade`, `corrected_sentence: str | None`, `explanation: str`, `praise: str | None`.
   - `SessionReviewResponse` — контейнер с полем `reviews: list[SentenceReview]` для возврата массивом.
2. Эта схема будет использована в будущем при вызове `client.beta.chat.completions.parse`.

## Критерии готовности (DoD)
- [x] Код валидирует и описывает нужные поля из PRD (Окно Traffic Light Report).
- [x] В перечислений оценок используется `Grade` из `models.practice_log`.
- [x] Результирующим ответом выступает массив отзывов.
