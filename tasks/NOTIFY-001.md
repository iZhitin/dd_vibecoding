# Отчет по задаче [NOTIFY]-001: Интеграция Resend для отправки email

## Что было сделано:
1. Создан сервис `backend/app/services/email.py` для асинхронной отправки email-сообщений через библиотеку `resend`.
2. Реализована логика повторных попыток отправки (Retry) при сбоях (3 попытки с exponential backoff).
3. При отсутствии `RESEND_API_KEY` сервис корректно логирует предупреждение и игнорирует попытку отправки, не вызывая краша приложения.
4. Обновлена функция `request_magic_link` в `backend/app/services/auth.py`. Теперь вместо вывода magic-ссылки в консоль (mock) выполняется реальная отсылка по email посредством сервиса `send_email`. 
5. Добавлено покрытие тестами `tests/test_email.py` для функции рассылки, включая сценарии отсутствия ключа api, успешной отправки и отработки retry mechanics.
6. Выполнена проверка линтерами (ruff), а также общие тесты pytest. Внесены изменения в файл HISTORY/CHANGELOG.

## ADR
Для данной задачи новые архитектурные решения не принимались (ADR не добавлено), использовалась конфигурация Resend, описанная в `TECHSPEC.md` / `PRD.md`.
