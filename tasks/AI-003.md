# Отчёт по задаче AI-003: Реализовать LLM Review Worker

## Цель
Создать асинхронную задачу для проверки LLM (OpenAI) всех введенных предложений пользователя в сессии, обновления оценки (grade), выставления feedback и последующего изменения веса карточек в SRS модуле.

## Что было сделано
1. В файле `backend/app/workers/llm_review.py` создана функция `review_sentences(ctx, session_id: UUID)`.
2. В функции проверяется наличие `OPENAI_API_KEY` и инициализируется `AsyncOpenAI` клиент.
3. Происходит выборка всех предложений (`logs`) из завершенной пользовательской сессии (SessionStatus=`COMPLETED`).
4. Формируется один массивный system prompt для модели `gpt-4o-mini`, в котором описывается роль, критерии оценок (`GREEN`, `YELLOW`, `RED`, `GREEN_STAR`) и подставляются переводы вместе с фразами пользователя.
5. Вызывается `beta.chat.completions.parse` с `response_format=SessionReviewResponse`.
6. Реализован `Exponential Backoff` (таймаут 30s) c максимумом в 3 попытках запроса к API.
7. Для каждого лога проставляется `grade` и `llm_feedback` в формате JSON.
8. После этого, для каждой карточки вызывается метод `update_weight_after_review` и затем все изменения атомарно коммитятся в БД.

## Критерии готовности (DoD)
- [x] Воркер успешно обрабатывает задачу `review_sentences` и парсит ответ LLM.
- [x] При ошибках API есть алгоритм backoff до 3 раз; при недоступности поля заполняются как `None`.
- [x] `Card.weight` обновляется после оценки.
- [x] Экранирование пользовательских строк, так как они попадают в промпт.

## Привязка к ADR
*Специфических решений нет, однако был использован `parsedChatCompletion`, обеспечивающий вывод чистого JSON на основе Pydantic-схем, описанных в AI-002.*
