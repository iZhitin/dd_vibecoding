# Отчет по задаче [UI-003]

## Что сделано:
1. Создана страница `CapturePage` для занесения пользователем новых слов.
2. Реализована интеграция с эндпоинтом API авто-перевода (`POST /api/translate`).
3. При вводе слова пользователем и нажатии Enter, UI отображает Optimistic UI через skeleton loader для блоков перевода и контекстного предложения.
4. Добавлена возможность отредактировать перевод вручную как при успешном авто-переводе, так и при fallback (когда перевод не приходит в ответ).
5. Создан Zustand стор `useCaptureStore` для инкапсуляции состояния формы.
6. Выполнена интеграция компонента с API для сохранения карточек (`POST /api/cards`).
7. Добавлены красивые анимации элементов с помощью `framer-motion` (slide in / fade in эффекты).

Задача "Создать страницу Capture (ввод нового слова)" полностью выполнена, обновлен CHANGELOG, закрыта в BACKLOG.md. Линтеры и форматтеры прошли успешно. Дополнительных ручных действий не требуется.
