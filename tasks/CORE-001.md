# Отчет по задаче [CORE-001]

## Цель
Реализовать API для Capture (ввод нового слова). Требовалось сделать сохранение карточки в БД и возможность получить список карточек текущего пользователя с пагинацией.

## Сделано
1. **Создан сервис работы с карточками `app/services/card.py`:**
   - Реализована функция `create_card` для создания карточки. Для новых карточек вес по умолчанию равен `1.0`, дата следующего прохождения `next_review_at` выставляется в значение `now(timezone.utc)`.
   - Реализована функция `get_user_cards` с пагинацией (используются `limit` и `offset`). Возвращается кортеж из списка карточек и общего количества.
2. **Созданы роуты `app/api/routes/cards.py`:**
   - Добавлен POST `/api/cards` для создания карточки (protected endpoint).
   - Добавлен GET `/api/cards` для получения всех пользователя с пагинацией и сортировкой по `created_at` desc.
   - Эндпоинты покрыты авторизационным миддлварем `get_current_user`. Модели для входных и выходных данных используются из готового `app/schemas/card.py`.
3. **Тестирование:**
   - Написаны unit тесты `backend/tests/test_cards.py` с использованием `AsyncMock` для работы с БД, что позволило надежно тестировать логику без реального подключения к PostgreSQL.
   - Тесты проходят: 14/14 успешно.

## Принятые решения
- Использована генерация timezone-aware datetime для `next_review_at`. (встроенная функция `datetime.utcnow()` объявлена устаревшей, использована `datetime.now(timezone.utc)`).
- Тесты написаны с помощью `mock`, т.к. не имелось доступного фикстурного движка для БД "из коробки" в текущем проекте.
