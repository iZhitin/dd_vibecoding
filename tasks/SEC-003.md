# Отчет о выполнении задачи [SEC-003]

## Описание задачи
Настройка CORS политик, добавление Security-заголовков для защиты от XSS (в дополнении к санитизации строк), clickjacking и content-sniffing оверлей.

## Ключевые изменения
1. В `backend/app/main.py` добавлен слой `middlewares`:
    - `SecurityHeadersMiddleware`, добавляющий заголовки `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `X-XSS-Protection: 1; mode=block` и строгий `Referrer-Policy`. 
2. Настроено CORS правило для допущения валидных origins (`APP_URL`), вместо `*`. 
3. В конфигурацию NGINX `nginx.conf` добавлены директивы установки CSP `Content-Security-Policy`. 
4. Теперь XSS инъекции блокируются браузерами, даже если вредоносные скрипты были закешированы.

## Статус
Выполнено.
